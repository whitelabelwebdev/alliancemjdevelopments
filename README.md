# Alliance MJ Developments: Homepage Redesign

Static homepage concept for [alliancemjdevelopments.com](https://alliancemjdevelopments.com/).

## Structure

```
index.html
assets/
  css/style.css     All styles (custom properties, responsive breakpoints at 1180, 980 and 680px)
  js/main.js        Header state, mobile menu, development tabs, portfolio filter, hover previews, reveal animations
  images/           Logo, hero and project renders from the client site
  icons/            Favicons
  fonts/            Self-hosted Afacad Flux and Instrument Serif (woff2)
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
